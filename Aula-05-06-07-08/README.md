12. SRS simplificado:

Introdução: objetivo e descrição do sistema.

Requisitos Funcionais: funções que o sistema deve fazer, como cadastrar usuário, fazer empréstimo, realizar pedido e efetuar compra.

Requisitos Não Funcionais: segurança, desempenho, facilidade de uso e disponibilidade.
