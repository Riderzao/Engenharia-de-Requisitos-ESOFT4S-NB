Engenharia de Requisitos - Aula 01

Situações
Em um E-commerce fictício, o cliente pediu “um checkout simples”. Isso pode significar compra em 1 clique ou um formulário completo - qual desses o time deveria construir?
Analogia da casa sem planta, construir um software sem levantar requisitos é como erguer uma casa sem projeto arquitetônico. Que problemas apareceriam nesse cenário?

Reflita
Alguém aqui já usou um aplicativo que claramente não fazia o que vocês esperavam? O que acham que deu errado no processo de construção dele?
Por que é mais barato corrigir um erro de requisito no início do projeto do que perto da entrega?

Exercício – Requisitos do dia-a-dia
Escolher uma situação cotidiana (planejar uma viagem, organizar uma festa, comprar um carro) e listem 3 “requisitos” dessa situação, classificando cada um como funcional (o que precisa acontecer) ou não funcional (como deve acontecer / restrição).

Resposta - Compra de carro
Requisito: carro ter ar condicionado / Funcional
Requisito: custar até 50k / Não Funcional
Requisito: deve ser econômico / Não Funcional
